# UX Sprint — Commercial UI Transformation

**Goal:** Transform Patent Pulse from technically functional to
commercially compelling. Not adding features — surfacing existing
intelligence honestly and beautifully.

**Standard patent:** USPTO:8929360 (Cisco, id
`003b969f-dae5-4303-b9d5-6a4cdafdd8ca`, 10/12 fields)

## Steps

### s0. Pre-sprint orientation ✅
Route inventory, standard patent selected, decisions locked.

### s1. UX audit matrix ✅
Full matrix: route-by-route strengths, gaps, priorities (P0/P1/P2).

### s2. IA proposal
Document current vs proposed sitemap. Key changes:
- `/today` is primary command center; `/dashboard` removed from nav
- `/themes` labeled "Topics" in UI; `/topics` redirect deferred
- `/news` → section on Today, not a separate route
- Add `/admin/data-health` to admin sidebar

### s3. First-time user experience
P0: Add empty states to Today, Topics, Watchlist.
Add starter topic suggestions. Add "Your First Topic" flow.

### s4. Today command center
P0 redesign: add empty state, data freshness bar, patent highlights,
starter topics, personalization skeleton.

### s5. Upgrade PatentCard
P1: Add image thumbnails, abstract availability badge, source status,
figure link. Consistent across browse/search/watchlist/topics grids.

### s6. Upgrade Patent Detail
P0: Add source data panel (field availability matrix for this patent).
Surfacing data gaps honestly. Image thumbnail in header.

### s7. Upgrade Expiry Radar
P1: Promote legal caveat, add thumbnails, add "verify at source" links.

### s8. Upgrade Trends
P1: Narrative snippets in trend cards, subscribe-to-trend action,
drilldown links to patents.

### s9. News/Highlights surface
Add a "What's New" section to Today — recent AI content, system events,
new patent highlights. Not a standalone route.

### s10. Visual system pass
Consistency sweep: typography, spacing, color tokens, loading states,
error states, empty states across all routes.

### s11. Verification
- Pytest: 341 passed, 3 xfailed, 0 failed (or growing)
- Frontend: `npm run build` clean
- All routes: 200, no console errors
- AGENTS.md grep: zero forbidden phrases
- Browser smoke: Today → Detail → Expiry → Trends → Topics → Search → Watchlist
